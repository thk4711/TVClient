# Code of Conduct

## Our standard

Be respectful and constructive. Harassment, personal attacks, discrimination and
other unprofessional conduct are not welcome in this project's spaces, including
issues, pull requests and discussions.

## Scope

This applies to all project spaces and to anyone representing the project in
public spaces.

## Reporting

Report unacceptable behavior through GitHub. For a participant, use the
["Report abuse"](https://docs.github.com/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
option on their content or profile. For content, use the report link on the
issue, pull request or comment.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead; do not
disclose them in public reports.

Maintainers may edit, hide or remove contributions, and restrict participation,
for conduct they consider inappropriate.
