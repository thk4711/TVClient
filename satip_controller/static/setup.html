WELCOME TO YOUR RECEIVER

SAT-IP first setup

Welcome! Follow these steps to start watching TV. No password is needed on your home network.

User manual — illustrated setup and operating instructions ↗

Your receiver and controls

Infrared and USB keyboards are always enabled together. Press an arrow or OK button on either to test it.

USB keyboards work automatically. For an additional USB remote, select it and choose Use this control.

TV source discovery

OpenWebif HTTP access on a private LAN is required. Authentication and HTTPS are not supported. Discovery checks port 80; enter other ports manually. No zap or settings commands are sent.

Import Enigma2 bouquets

Select up to 16 genuinely free-to-air TV bouquets. Overlapping service references are deduplicated. Import replaces the available Enigma2 catalogue with validated channels from this selection; matching favourites keep their order. Unsupported and unavailable streams are excluded. An unsuccessful or stopped import retains the previous lineup.

Enter or discover the receiver above and load its bouquets. Validation may take many minutes.

1. SAT-IP server

Add server by description URL

If multicast discovery finds no server, enter its SAT-IP XML description URL. Supported HTTP ports: 80, 8080 and 38400.

2. Select a tuner and search channels

Choose the tuner to use for the next search.

Satellite: Astra 19.2°E. The transponder list is selected automatically.

A complete channel search can take more than ten minutes. You can stop the search and keep channels already found.

Choose your favourites

A starter selection is checked automatically, preferring HD where available. Choose your channels. Once the search finishes or you stop it, confirm your selection to arrange them.

Arrange your favourites

Drag and drop your favourites into the order you want. With a keyboard, focus a drag handle and use the Up and Down keys.

    Advanced: boot preferences

    Optional settings from the SD card are imported and the boot file is cleaned up automatically. You can retry cleanup here if needed.

    Restoring the file is not secure erasure of flash storage.
